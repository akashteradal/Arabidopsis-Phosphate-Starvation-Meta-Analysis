# Principal Component Analysis

This directory contains the Principal Component Analysis (PCA) results generated during the RNA-seq analysis.

PCA was performed to evaluate sample-level variation, assess biological replicate clustering, and examine the separation between control and phosphate-starved samples.

The PCA results were used to assess the consistency of biological replicates and the overall transcriptional differences between control and phosphate-starved conditions across the five RNA-seq datasets.

## Datasets

PCA results were generated for:

- GSE183312
- GSE128250 (1 h)
- GSE128250 (2 h)
- GSE217158
- GSE278345

The PCA plots were used as part of the quality assessment and exploratory analysis before downstream comparative interpretation.
