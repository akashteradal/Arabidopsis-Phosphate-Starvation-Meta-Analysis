# Results

This directory contains the major results generated from the comparative transcriptomic meta-analysis of Arabidopsis thaliana under acute and chronic phosphate starvation.

The results include outputs from differential expression analysis, meta-analysis, and functional enrichment analysis used to identify conserved transcriptional responses and biological processes associated with phosphate starvation.

## Analysis Categories

- Differential Expression Analysis
- PCA and Sample-Level Analysis
- Volcano Plots
- Meta-analysis and Conserved DEG Intersections
- Gene Ontology Biological Process Enrichment
- Candidate Gene Analysis

The results are organized according to the major stages of the analysis and are intended to document the findings reported in the project.
