# Volcano Plots

This directory contains the volcano plots generated from the DESeq2 differential expression analysis.

Volcano plots were used to visualize the relationship between statistical significance and the magnitude of gene-expression changes between phosphate-starved and control samples.

The plots were generated for the RNA-seq datasets analyzed in the study and were used to visually examine differentially expressed genes.

## Differential Expression Criteria

- Upregulated genes: log₂FC > +1.5
- Downregulated genes: log₂FC < −1.5
- Statistical significance: padj < 0.05

The volcano plots complement the DESeq2 differential expression results and provide a visual representation of significant transcriptional changes.
